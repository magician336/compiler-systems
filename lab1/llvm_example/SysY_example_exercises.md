# LLVM IR 和 RISC-V 实验练习

1. **定位变量**：在 `scale_array` 中找出循环变量 `i`、数组参数和长度参数对应的 `alloca/load/store`，说明每条指令的作用。
2. **定位基本块**：画出 `sum_positive` 的控制流图，标出循环条件、循环体、正数分支、跳过分支和循环结束块。
3. **观察数组寻址**：解释 `getelementptr` 如何把数组下标转换成元素地址。
4. **观察分支**：把平均值阈值从 `5` 改为 `10`，重新生成 LLVM IR，比较 `icmp` 的立即数变化。
5. **优化对比**：分别用 `-O0` 和 `-O2` 生成 IR，记录循环、局部变量和内存访问发生的变化。
6. **SysY 数组参数**：说明 `int values[]` 在 LLVM IR 中为什么表现为指针参数，但源程序本身不需要显式指针语法。
7. **边界实验**：令数组长度为 `0`，验证 `classify_average` 的除零保护分支。
8. **目标代码验证**：检查 `SysY_example.riscv.s` 中的函数标签、数组寻址、分支和运行库调用，并比较主机与 RISC-V simulator 的输出。
